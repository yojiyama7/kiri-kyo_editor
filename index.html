操作ガイド

基本操作・モード

  • NORMAL が構造編集モードです。構造図をクリックすると、その単語・slot・下線などを選択できます。
  • i で INSERT に入り、上の英文を通常のテキストとして編集します。Esc で NORMAL に戻ります。
  • 入力テキストの改行は文境界です。下線・T・矢印は文境界を跨げません。
  • 英文を編集した場合、同じ位置にある既存の標識・構造は可能な範囲で保持されます。

カーソル移動

  • h/l：表示上のslotを左/右へ移動します。通常slotだけでなく、二重slotやTの左右slotもそれぞれ独立した1位置として通過します。
  • j：現在のslotを含む最も内側のV下線へ移動します。さらに押すと外側の包含構造へ進みます。包含構造がなければ次の入力行へ移動します。
  • k：通常のV下線から、その内部の最左slotへ戻ります。通常slot上で外側構造がなければ前の入力行へ移動します。
  • 0：先頭位置へ移動。$：文末ダミー位置へ移動します。文末ダミーは文末境界へ記号を置くためにも使います。

働きの標識

  • /：現在のslotへ任意の文字列を直接入力します。通常slot、二重slot左右、T左右、V下線slot、V下線T左右で共通です。既存文字列の末尾から編集を開始し、Enterで確定、Escで入力開始前へ戻し、Backspaceで末尾1文字、Deleteで全文字を削除します。
  • s → S、s' → S'、v → V、o → O、c → C、m → M。
  • con → 接、pre → 前。
  • a → a、ad → ad、ado → 副詞的目的格、ac → aC、aux → aux、nc → nC。
  • 1〜5 → (1)〜(5)、-の後に3〜5 → -(3)〜-(5)。
  • a / ad / ado など複数キーの標識は途中状態が保留表示されます。Esc で保留入力を取り消せます。別の操作へ進むと、成立している候補は確定されます。
  • x：現在選択している働きの標識を削除します。
  • d：通常slotを左右2つのslotへ切り替えます。もう一度押すとsingleへ戻ります。左右はh/lで個別に選択します。

T（準動詞）

  • t：現在の単語、または選択中のV下線をT化します。tはT化専用で、解除には使いません。
  • Tは左slot・右slotの2位置を持ち、h/lでそれぞれ選択できます。
  • X：単語TならTを削除します。V下線TならTだけを外して通常のV下線へ戻します。

V下線・連続/非連続範囲

  • V：現在のslotから下線範囲の指定を開始します。選択対象はtokenではなく表示上のslotです。
  • 範囲指定中はh/lで現在の部分範囲を伸縮します。現在位置/選択中は灰色、Vで固定済みの部分範囲はオレンジで表示されます。
  • 選択中にもう一度Vを押すと、その部分範囲を固定します。その後h/lで離れた位置へ移動し、再度Vで次の部分範囲を開始できます。
  • Enter：すべての部分範囲を1つの下線groupとして確定。Esc：固定済み部分も含め、範囲指定全体をキャンセルします。
  • 部分範囲が連続していれば1本の下線、離れていれば複数の下線として表示されます。非連続部分には同じ色の塗りつぶし正方形が付き、同じgroupであることを示します。
  • 下線は重なり・包含・同一範囲を許します。1つの下線groupは、その内部に含む表示物すべてより下に、全部分を同じ高さで描画します。
  • 通常のV下線自身にも独立したsingle slotがあります。下線を選択して標識キーを入力すると、このslotへ標識を設定できます。
  • jで内部slotから包含するV下線へ、kで通常V下線から内部の最左slotへ移動できます。
  • tでV下線全体をT化できます。XはV下線TならTだけ解除し、通常V下線なら下線構造を削除します。
  • U：現在のV下線groupを解除し、そのgroup構造自体を削除します。

境界記号

  • [ ] < > ( )：NORMALのまま、現在位置の左側の境界へ記号を追加します。複数文字を重ねて保持できます。
  • b：境界編集モードへ入ります。h/lで境界を移動、0/$で文頭/文末境界へ移動します。
  • 境界編集モードでは同じ6種のキーで記号を追加し、Backspaceで末尾1文字削除、x/Deleteでその境界の記号を全削除します。
  • Esc、Enter、または再度bで境界編集モードを終了します。

修飾矢印

  • 始点にできるのは、標識が a / ad / 副詞的目的格 のslotです。そのslot上でrを押すと終点選択を開始します。
  • 終点選択中もh/l/j/k/0/$で移動できます。
  • Enter：現在slotを終点として確定。Esc：取消。rをもう一度押すと始点を選び直します。
  • 1つの始点から保持できる矢印は1本です。新しく確定すると、その始点からの既存矢印を付け替えます。
  • R：現在slotを始点とする矢印を削除します。矢印は文境界を跨げません。

削除・履歴

  • x：標識削除。X：現在選択中のT/V下線構造を1段削除。U：V下線groupそのものを解除。
  • u：undo。Ctrl-r：redo。標識・境界・T・下線・二重slot・矢印・英文編集など文書内容の変更が対象です。
  • h/l/j/kなど、カーソル移動だけの操作は履歴に入りません。
  • aux の a→u→x を入力中の u はundoではなく標識入力として扱われます。

内部表現

  • 「内部表現（JSON・リアルタイム）」には現在の文書構造を常時表示します。
  • 存在しない標識・T・下線・境界・矢印などは、空値を並べず不要なキー自体を省略します。
  • 下線の範囲はslot参照として保持され、Tの左右slotやV下線のslotも部分指定できます。
